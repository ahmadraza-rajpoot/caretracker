# Care Track

Care Track is a healthcare audit management SaaS designed to help healthcare teams organize and manage their audit activities through a centralized dashboard.

## Tech Stack

- Next.js
- React & TypeScript
- Tailwind CSS & shadcn/ui
- Supabase Authentication
- MongoDB (planned for application data)

## Features

- User authentication (Sign Up / Login)
- Protected dashboard routes
- Sidebar navigation
- Audit management (in development)

Configure your Supabase environment variables in `.env.local` before running the application.
